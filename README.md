# Выпускная квалификационная работа магистра

## Предотвращение взаимных блокировок автономных агентов методами централизованного планирования

Студент: Бирюков Виктор Владимирович

Группа: М8О-208СВ-24

Научный руководитель: Судаков Владимир Анатольевич

## Цель и задачи работы

**Цель:** разработать методы глобального планирования движения группы автономных доставочных агентов по графу дорожной сети с узкими местами, исключающие взаимные блокировки и обеспечивающие эффективное прохождение конфликтных участков.

**Объект:** совместное движение группы автономных агентов последней мили в общей дорожной сети.

**Предмет:** алгоритмы глобального планирования и разрешения конфликтов в узких местах графа дорожной сети.

**Задачи:**

1. Формализация модели задачи глобального планирования группы агентов на взвешенном графе с узкими местами;
2. Анализ существующих методов планирования (MAPF, CCBS) и выявление их ограничений;
3. Разработка альтернативных методов: семафорный и реверсный резолверы конфликтов поверх независимых A\*-маршрутов;
4. Формирование набора метрик качества и реализация воспроизводимой среды моделирования;
5. Подготовка тестовых сценариев и сравнительный эксперимент на графах разного масштаба и плотности агентов.
